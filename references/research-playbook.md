## Build the visual and commercial vocabulary

Translate the visible product into terms that sellers use. Combine:

```text
[function/use] + [product type] + [material] + [style/pose/form]
+ [distinctive feature] + [commercial intent]
```

Example for a white marble angel memorial:

```text
white marble angel headstone black granite base
seated angel memorial monument with roses and cherub
custom marble angel cemetery monument manufacturer
汉白玉 坐天使 墓碑 黑金沙 底座 厂家
天使雕像 墓碑 定制 供应商
```

Do not let a visual caption replace category terms. Sellers may call a memorial
a headstone, gravestone, monument, marker, grave statue, or cemetery sculpture.
Try the related nouns buyers and manufacturers actually use.

## Query patterns

Use several query families rather than one long prompt:

1. **Exact appearance:** product type + visible defining features.
2. **Category synonym:** replace “statue” with “sculpture”, “ornament”, or
   “monument”; replace one material with nearby trade terms.
3. **Commercial intent:** `manufacturer`, `factory`, `supplier`, `wholesale`,
   `custom`, `OEM`, `for sale`, `bulk`.
4. **Site constraint:** run `site:` searches for Alibaba, Made-in-China,
   Global Sources, DHgate, 1688, Amazon, Etsy, Wayfair, or Houzz when useful.
5. **Regional:** add production or export regions only when the user cares about
   location or logistics.
6. **Negative differentiation:** add a competing type when results are
   contaminated, such as `garden statue` when `cemetery monument` results are
   being drowned by lawn ornaments.

For a text-only request, first restate the required attributes. Then search the
core noun broadly and use discovered listings to learn better seller
vocabulary.

## Reverse image search

Use a public visual search interface only when the current image, browser, and
task permit upload. Google Lens or Bing Visual Search are common routes; other
public engines can help when one source is weak or inaccessible.

Prepare two queries when the background dominates:

- the original image, to trace exact reposts;
- a subject-focused crop, to find compositionally similar products.

Do not crop or retouch away source marks for publication. The crop is only a
query aid. Keep the unmodified original alongside the research record.

Review visual results by anatomy and construction, not just color:

- silhouette and proportions;
- base shape and supporting structure;
- pose and limb placement;
- attached ornaments, roses, inscriptions, or hardware;
- material appearance and finish;
- scale implied by setting.

Reverse-image results often include the same copied image across aggregator
sites. Follow the chain toward the earliest or most complete source page. If an
image appears only on social boards, label it as an untraced visual reference.

## Platform roles

Platform capabilities and accessibility change. Use the source for what it can
actually prove:

| Source type | Useful for | Limits |
| --- | --- | --- |
| Google/Bing image search | Discovering visual matches and vocabulary | The image result is not supplier proof |
| Alibaba / Made-in-China / Global Sources | Public supplier, product, and export listings | Login walls, regional variants, and stale listings |
| 1688 / Taobao / Tmall | Chinese domestic supply and product variants | Often requires account or app access |
| DHgate / Amazon / Etsy | Retail product presentation and variant comparison | Retail listing is not necessarily the manufacturer |
| Pinterest / Houzz / Instagram | Style vocabulary and inspiration | Reposts and untraceable authorship are common |
| Manufacturer’s own site | Best evidence for product, contact, and origin | Product may be custom or no longer current |
| Museum / Wikimedia / stock site | Rights-cleared editorial or commercial imagery | May be inspiration rather than the exact product |

For supplier sourcing, a marketplace profile is a lead, not a fully verified
factory. Record whether the platform label says manufacturer, trading company,
or unspecified; verify business identity and capability separately before a
purchase decision.

## Source verification

Open and inspect each shortlisted page. Confirm:

- page title and visible image correspond to the result;
- product type and intended use match;
- key visual features are visible, not inferred;
- seller/manufacturer identity is stated;
- image is not a collage, mockup, reference rendering, or isolated detail;
- page is public and still loads;
- any price, MOQ, material, or customization claim is directly supported.

Use `[VERIFY]` in notes for facts that are absent, ambiguous, or only implied by a
thumbnail. Record the exact page checked, not a search-result redirect URL.

## Rights and reuse

Record one of:

- `licensed`: explicit license or permission and a link to its scope;
- `supplier-permission`: supplier has given permission for the stated use;
- `reference-only`: no reuse permission found;
- `unknown`: source or rights not traceable.

Do not interpret public accessibility as permission to republish. For a website,
advertising, or print use, require a license or documented supplier permission.
When the user asks specifically for website-ready images, prefer manufacturer
press assets, explicit supplier authorization, public-domain/open-license
collections, or commissioned photography.

## Stopping and reporting limitations

Stop when the top 3–5 matches are stable and additional results repeat the same
product or image. Report material search gaps:

- image upload unavailable or refused;
- marketplace required login;
- CAPTCHA or regional block prevented access;
- only reposts, no original page;
- source page removed or product no longer listed;
- image too low-resolution to confirm a distinctive feature;
- rights status unknown.

Do not pad the list to hit a number. A smaller set of traceable matches is more
useful than many unverified thumbnails.
